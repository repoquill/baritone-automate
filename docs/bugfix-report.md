# 缺陷修复与验证记录

检查日期：2026-10-18（发版 **0.1.2**，2026-10-22）。目标环境：Minecraft 26.3、Fabric、Java 25。

本次完成源码检查、缺陷修复、回归测试和发布包检查。下面记录已修复的问题及自动化验证范围。

## 已修复的问题

| 范围 | 问题与修复 |
| --- | --- |
| 阶段计时 | 暂停后保留已消耗的超时预算；暂停期间冻结计时。运行时改用单调时钟，避免系统时间调整影响超时。 |
| 运行状态 | 玩家死亡时终止当前运行；阶段进入和执行时的异常转成受控失败。重试、跳过、取消和重新开始会清理待办容器操作。 |
| 游戏生命周期 | 断线时清理运行状态和门框建造计划；单机实际暂停游戏时同步暂停运行，恢复游戏后仅恢复由游戏暂停的运行。 |
| 挖矿与熔炼准备 | 修复首次挖矿没有启动、挖矿进程被替换后不再继续的问题；补充石头和深板岩采集，并在粗铁数量足够后开始熔炼。 |
| 合成任务 | 合成数量按完整配方批次计算；临时等待放料时重试原格；修复嵌套制作熔炉反复重启。批量合成获得相应的执行时间。 |
| 容器材料 | 先处理未完成的合成或熔炼任务，再重新判断阶段库存；清理旧配方材料，并检查鼠标持物和输入槽冲突，避免材料暂存在合成格时误判缺料。 |
| 连续熔炼 | 优先取出成品；利用现有燃烧时间、输入和燃料；先装入所需粗铁再点燃。超过 64 个粗铁时等待输入槽腾出空间，不再向满槽放料。已有其他原料的熔炉会报告占用。 |
| 配方与燃料 | 按实际木材种类制作对应木板，补充木材和竹块匹配；修正半次熔炼精度的燃料计算，排除不可燃的诡异和绯红木材；原版配方不再接受其他命名空间中同名的物品。复用已有工作台。 |
| 下界门 | 采集黑曜石要求钻石镐或下界合金镐。自动建造使用含四角的完整门框，固定建造位置和方向；部分建造和超时重试保留计划，已有点燃传送门时直接使用。修复燧石采集被连续取消、接近传送门后提前停止寻路的问题。 |
| 要塞与末地门 | 从下界返回主世界后再扔末影之眼；切换物品或等待操作不再消耗投掷次数；最后一次投掷和最后一颗眼睛都继续追踪飞行目标。填充末地门前可用现有材料补做末影之眼。 |
| 战斗 | 弓箭瞄准、蓄力后释放，并检查箭矢；暂停和取消时结束本次持弓动作。龙近战攻击可受击部位，使用实际交互距离。追踪移动目标时节流更新寻路，处理被拒绝的请求，完成或取消战斗时停止寻路。 |
| 世界交互 | 放置、点火和使用物品按实际交互结果判断成功；实体扫描限制在指定球形距离内。 |
| Baritone 进程 | 启动新的寻路、挖矿、探索、跟随或农场任务前释放上一个进程，防止进程竞争。 |
| 参数和设置 | 拒绝非有限距离、无效数值和空的 `#` 命令；设置修改及重置写入配置文件。修复探索范围极值溢出，限制过大范围；每次探索使用独立的临时过滤文件。 |
| 操作台 | 活跃通关时统一控制阶段、战斗和容器任务；按钮随运行状态刷新。修复数字设置使用旧值比较、搜索后光标位置丢失，以及窄窗口下部分控件越界的问题。 |
| 构建与说明 | Windows 包装器在缺少 Java 时正确退出；README 中的发布包版本统一为 **0.1.2**，更新运行行为和验证边界。 |

## 行为变化

- 自动建造下界门需要 **14 块黑曜石**，用于含四角的完整 4×5 门框。
- 自动挖掘黑曜石需要 **钻石镐或下界合金镐**；铁镐不再被视为足够的采集工具。跳过钻石阶段时也要满足该条件，或提前备好黑曜石。
- 暂停后继续使用剩余超时时间；暂停不会刷新整段超时预算。

## 验证结果

使用 JDK 25 执行：

```powershell
$env:JAVA_HOME = (Get-ChildItem -LiteralPath '.jdk' -Directory | Select-Object -First 1).FullName
$env:GRADLE_USER_HOME = Join-Path (Get-Location) 'agent-tools\gradle-home'
& .\gradlew.bat clean build --console=plain --no-daemon
```

`.jdk` 是本次准备的本地构建环境；也可以把 `JAVA_HOME` 指向自行安装的 JDK 25。首次构建需要下载依赖。

- 完整清理、主源码和客户端源码编译、测试、源码包及发布包生成均成功，10 个任务全部执行。
- **11 个测试类，116 项测试：失败 0、错误 0、跳过 0。**
- 测试覆盖阶段状态与超时、物资和传送门流程、合成熔炼、物品移动、探索范围、数值设置、战斗判定和界面边界。
- 新增超过一组粗铁的熔炼回归用例，在修复前复现“输入槽已满”失败，修复后完成 65 个铁锭的生产。
- `verifyBaritoneNotNested` 通过；另检查发布 JAR，客户端入口存在，版本为 **0.1.2**，没有 `baritone/` 类和嵌套依赖 JAR。

## 验证范围

本次没有启动真实 Minecraft 世界或与可运行的 Baritone 模组进行联调。单元测试使用模拟的世界、物品栏和容器；客户端适配代码已编译并核对游戏 API，但尚未在游戏内验收容器同步、复杂地形中的放置和跨维度寻路、弓箭命中及完整屠龙流程。

因此，上述结果证明已发现缺陷的修复和当前自动化检查通过，不代表已证明所有游戏场景无缺陷或一键通关必然成功。
